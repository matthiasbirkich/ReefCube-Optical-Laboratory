## [Unreleased]

### Added

- Initial ReefCube Optical Laboratory Python package
- Modular tools for environmental spectroscopy and optical sensor data
- AS7343 channel definitions and spectral processing utilities
- Spectral reconstruction and wavelength-related calculations
- Calibration and regression utilities
- Photosynthetic photon flux density calculations
- Measurement, storage and deployment modules
- Statistical analysis and sensor-comparison utilities
- Publication-oriented visualization functions
- Complete demonstration notebook
- Direct Google Colab integration
- Automated package tests for Python 3.10, 3.11 and 3.12 using GitHub Actions
- MIT License
- Citation metadata in `CITATION.cff`
