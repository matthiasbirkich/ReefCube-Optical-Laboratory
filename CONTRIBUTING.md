Thank you for your interest in ReefCube Optical Laboratory.

How to contribute

* Fork repository
* Create feature branch
* Commit
* Push
* Open Pull Request

Coding Style

* Python ≥3.10
* PEP8
* Type hints
* NumPy docstrings
* Black formatting

Documentation

Every public function should include

* Parameters
* Returns
* Raises
* Examples (if appropriate)
